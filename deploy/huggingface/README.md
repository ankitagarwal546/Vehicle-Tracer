# VITRA — Vehicle Identification & Trace Analytics

Upload CCTV clips, track every vehicle, recover licence plates character by character, and trace vehicles across cameras with an audit trail.

Sign-in is required. The registry in this demo is synthetic, and data on this Space resets whenever the Space restarts.

Source code and full documentation: https://github.com/ankitagarwal546/Vehicle-Tracer
